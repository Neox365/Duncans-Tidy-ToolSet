# Duncan's Tidy

Duncan's Tidy ist eine kompakte und ressourcenschonende Windows-Anwendung zur Systembereinigung und Optimierung. Das Tool entfernt temporäre Dateien, hält den Downloads-Ordner sauber und bietet eine integrierte Update-Prüfung mit digitaler Signatur.

---

## Funktionen

* Temp-Dateien bereinigen: Entfernt temporäre Systemdateien, Cache-Ordner und Absturzberichte.
* Downloads-Ordner verwalten: Automatische und manuelle Bereinigung veralteter Dateien.
* Automatische Updates: Prüft auf neue Releases über GitHub. Updates werden kryptografisch per digitaler Signatur verifiziert.
* Fehlerbehandlung: Überspringt schreibgeschützte oder momentan verwendete Dateien und protokolliert diese sauber.
* Minimaler Ressourcenverbrauch: Schneller Systemstart, extrem kleine Dateigröße (~500 KB) und keine externen Abhängigkeiten.

---

## Installation und Nutzung

1. Lade die neueste Version (DuncanTidy.exe) aus dem Bereich "Releases" herunter.
2. Starte die Anwendung per Doppelklick. Eine Installation ist nicht erforderlich.
3. Wähle die gewünschten Kategorien aus und klicke auf "Optimieren".
