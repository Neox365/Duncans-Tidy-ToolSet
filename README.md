# 🧹 Duncan's Tidy

**Duncan's Tidy** is a compact, fast, and resource-friendly Windows application designed for system cleaning and performance optimization. It features a modern dark theme, a responsive user interface, and protects your PC with cryptographically verified updates.

---

## ✨ Features

- **Temp Files & Caches:** Safely removes temporary system files, cache folders, and crash reports from your system.
- **Downloads Manager:** Automatic or manual cleaning of the Downloads folder (e.g., targeting files older than 30 days).
- **Startup Management:** Clear and intuitive control over startup programs via toggle switches, organized by users with an integrated search function.
- **High Security:** Automatic update checks via WinHTTP with digital signature verification to protect against supply chain attacks.
- **Intelligent Error Handling:** Read-only or locked files are automatically skipped instead of being forcefully removed.
- **Maximum Performance:** Zero external dependencies, a lightweight executable under 1 MB, and virtually no RAM or CPU usage when idle.

---

## 🚀 Installation & Usage

1. Download the latest release (`DuncanTidy.exe`) from the **[Releases](../../releases)** section.
2. Double-click the file to launch the application. No installation or administrator setup is required for basic functionality.
3. Select your desired categories and click **"Optimize"**.

---

- **Detailed File View:** Inspect file sizes and manually uncheck specific paths or individual items.

# Duncan's Tidy

Duncan's Tidy ist eine kompakte, schnelle und ressourcenschonende Windows-Anwendung zur Systembereinigung und Performance-Optimierung. Das Tool bietet ein modernes Dark-Theme, eine flüssige Benutzeroberfläche und schützt den PC durch kryptografisch verifizierte Updates.

---

## Funktionen

* Temp-Dateien & Caches: Entfernt temporäre Systemdateien, Cache-Ordner und Absturzberichte sicher vom System.
* Downloads-Manager: Automatische oder manuelle Bereinigung des Downloads-Ordners (z. B. für Dateien älter als 30 Tage).
* Autostart-Verwaltung: Übersichtliche Steuerung von Systemstarts per Toggle-Switch, unterteilt nach Benutzern und mit integrierter Suche.
* Höchste Sicherheit: Automatische Update-Prüfung über WinHTTP mit digitaler Signaturverifizierung zum Schutz vor Supply-Chain-Angriffen.
* Intelligente Fehlerbehandlung: Schreibgeschützte oder blockierte Dateien werden automatisch übersprungen und nicht gewaltsam entfernt.
* Maximale Performance: Keine externen Abhängigkeiten, eine Dateigröße von unter 1 MB und praktisch kein RAM-/CPU-Verbrauch im Leerlauf.

---

## Installation & Nutzung

1. Lade die neueste Version (`DuncanTidy.exe`) aus dem Bereich "Releases" herunter.
2. Starte die Anwendung per Doppelklick. Eine Installation oder Administrator-Einrichtung ist für die Grundfunktionen nicht erforderlich.
3. Wähle die gewünschten Kategorien aus und klicke auf "Optimieren".

---

* Disk Analyzer / Große-Dateien-Finder zur gezielten Speicherplatz-Freigabe
* Detaillierte Dateiansicht mit Größenangaben für gezieltes Abwählen einzelner Pfade
